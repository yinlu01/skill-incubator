# Obsidian 知识卡片化

把一篇阅读材料变成可入 Obsidian 子库、可直接微信转发的结构化卡片。

## 用户固定摄入流程（顺序执行）

1. **导读笔记**：写一段导读（材料主题、核心观点、价值点）。
2. **索引与时间线**：更新对应子库的索引文件与时间线条目。
3. **双链**：给相关概念、人物、报告加 `[[双链]]`。
4. **四问框架**：回填——这是什么？为什么重要？如何应用？与什么关联？

## 卡片输出格式

```markdown
## <主题>
**导读**：（3-5句）
**要点**：
- 要点1
- 要点2
**关联**：[[相关概念A]] · [[相关报告B]]
**四问**：
1. 是什么 — …
2. 为什么重要 — …
3. 如何应用 — …
4. 与何关联 — …
```

## 约定

- 显式双链，便于 Obsidian 图谱关联。
- 卡片可独立转发，含完整上下文，不依赖原文。
- 按材料主题归类子库：AI 技术卡片体系、国家科技创新体系/美国科研创新体系 等。
- Vault 路径见用户偏好：`~/Obsidian/`（如不同请替换为你的 Vault 根目录）。
