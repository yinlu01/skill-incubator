# AI 企业部署安全规范

企业级大模型/Agent 落地时的安全方案与评审框架。

## 六维度框架

1. **基础设施架构**：算力/网络/隔离、访问控制。
2. **企业数据分级**：按敏感度分级（公开/内部/机密/核心），定级与打标。
3. **加密传输**：数据分级加密、传输层与存储层加密、密钥管理。
4. **大模型安全网关**：防数据泄露、提示词注入防护、输入输出过滤、审计留痕。
5. **Agent 工程安全**：工具调用权限、记忆与知识库访问控制、多 Agent 间数据边界。
6. **交付效果测评**：安全与效果双重验收、红队测试、上线前评审清单。

## 输出方式

- **安全方案**：针对具体落地场景，逐维度给出方案与配置建议。
- **评审清单**：输出 checklist（维度 → 检查项 → 通过/整改）。

## 约定

- 面向与安全团队的评审沟通语境（用户已与安全负责人推进），输出可直接用于评审沟通。
- 风险项明确标「高/中/低」，并给整改建议。
