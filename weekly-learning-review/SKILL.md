# 学习周报

自动聚合一周学习数据，产出进度报告与调整建议。**数据源已固定，无需用户每次提供**。

## 数据源（本地路径，直接读取）

行者工作台项目目录：用户指定的工作台项目目录（默认 `~/WorkBuddy/当前项目/`，可由环境变量 `WORKBENCH_DIR` 指定）

| 文件 | 内容 |
|---|---|
| `agent_study_plan.json` | AI Agent 面试冲刺 16 周计划（2026-08-23 起 ~113 天） |
| `reading_plan.json` | 行者创业读书计划 |
| `weread_data.json` | 微信读书同步数据（划线/进度） |
| `review.json` | 复盘记录（含 AI 复盘分析） |

补充源：Obsidian Vault（`~/Obsidian/`）本周新增/修改的笔记，用于统计知识卡片产出。

## 周报结构

```markdown
# 学习周报 <起止日期>

## 总览
- 完成率 / 打卡天数 / 与上周对比

## 1. 阅读完成情况
（读书计划进度、微信读书划线要点、本周读完/在读书目）

## 2. Agent 面试冲刺进度
（当前周次、本周应学 vs 实学、落后/超前天数、整体完成百分比）

## 3. 知识产出
（本周新增卡片/笔记数、亮点卡片摘要）

## 4. 下周建议
（基于落后项给的 2-3 条具体调整，不超过 3 条）
```

## 约定

- 文件缺失或数据为空时如实标注「无数据」，不臆造。
- 进度数字必须有出处（哪个文件、哪个字段）。
- 建议要具体可执行（「周二、周四各补 1 个知识点」而非「加油」）。
- 输出 Markdown，适合归档到 Obsidian 或直接转发。
