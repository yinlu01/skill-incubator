# 每日市场分析报告

产出覆盖 A股 / 港股 / 商品 / 机构观点 的多维市场日报（对应每日 09:00 定时任务与工作日简报）。

## 数据与工具

- 先加载 `wb-finance-skill` 作为金融场景总入口。
- 行情数据：加载 `ifind-finance-data` skill 查询指数、个股、商品、宏观指标。
- 机构观点/新闻：用 `wb-finance-skill` 或 `ifind-finance-data` 的公告资讯检索取观点与评级变化。

## 报告结构

1. **宏观速览**：利率、汇率、海外市场隔夜表现。
2. **A股**：主要指数涨跌、量能、领涨领跌板块、资金流向。
3. **港股**：恒指/恒生科技、南向资金。
4. **大宗商品**：原油、黄金、有色等关键品种。
5. **机构观点**：主流券商当日观点与评级变化（注明来源）。
6. **风险提示**：单独小节列明需警惕的变量。

## 硬性约定

- **红涨绿跌**（中国惯例），图表与文字描述一律按此。
- 金额/货币默认 ¥（人民币），港币、美元需注明。
- 结论需有数据支撑，标注数据日期与来源。
- 输出结构化 Markdown，适合直接归档或转发。
