# 会议纪要工作流

把一段会议录音（微信语音、m4a/wav/mp3，常见约 25 分钟/段）变成可直接转发的结构化纪要。

## 工作流

1. **转录**：先加载 `openai-whisper` skill 完成本地语音转文字（无需 API 密钥）。多段录音逐段转录后按顺序拼接。
2. **结构化**：按下方模板把转写文本重构成纪要，不要照搬流水账。
3. **分类公告**：若会议内容含可对外发布的公告/通知信息，额外生成一段「分类公告」精简版，方便单独转发。

## 输出模板

```markdown
# 会议纪要：<主题>
- 时间 / 参会人 / 背景

## 议题与讨论
（按议题分段，要点式，保留关键数字与结论）

## 决议
（明确结论，逐条）

## 行动项
| 事项 | 负责人 | 截止时间 |
|---|---|---|

## 风险与待跟进
（未决问题、依赖、风险提示）
```

## 要点

- 保留专有名词与数字（VPC、端口、版本号、评审结论等），不臆造、不填空白。
- 行动项必须落到「负责人 + 截止时间」，缺失则标注「待定」。
- 输出 Markdown，默认写入 Obsidian 对应子库；用户也可直接复制转发。
