# MBA 运营管理案例分析

用运营管理课程的分析框架拆解案例、写作业。适用清华 MBA 运营管理课（2026 级）。定位是**学习辅助**：框架选择、公式推导、计算校验、结构示范，核心论述由用户自己完成。

## 框架路由表（按问题类型选主框架）

| 问题类型 | 信号词 | 用什么框架 |
|---|---|---|
| 流程效率 | 周期、产能、瓶颈、流程图 | 流程拆解 → 各工序 CT → 找瓶颈 → 流程产能与周期计算 |
| 排队/等待 | 等待时间、队长、服务台 | 利特尔法则 L = λW；排队论（M/M/1、M/M/s） |
| 库存管理 | 订货、库存成本、缺货 | EOQ、安全库存（z·σ·√LT）、ROP、报童模型（单周期） |
| 产能规划 | 扩产、加班、利用率 | 瓶颈产能 → 需求匹配 → 利用率 vs 阻塞 → 增减产能方案比较 |
| 质量/变异 | 良率、返工、波动 | 变异来源（common vs assignable cause）、六西格玛思想、田口损失函数思想 |
| 供应链 | 牛鞭、批量、交期 | 牛鞭效应成因、推拉边界、批量-周转权衡、风险共担 |
| 综合运营策略 | 竞争、定位、取舍 | 竞争维度（成本/质量/交付/柔性）+ 订单赢家 vs 订单资格要素 |

**规则**：一个案例最多选 2 个主框架（通常一个「计算框架」+ 一个「策略框架」），并在「案例定位」里说明为什么选它、为什么不选别的。

## 工作流（严格顺序）

1. **澄清案例**：读案例材料，列出给定数据（做成数据表）；确认作业到底问什么（区分「算数题」和「论述题」）。缺关键数据时先问用户，不臆造。单位换算（分钟/小时、件/批）在第一步就统一。
2. **路由框架**：按上表选定主框架，写明选择理由。
3. **结构化计算**：按公式手册（`references/formula-handbook.md`）逐步计算——每步先写公式、再代数字、再出结果、并解释这个数的**运营含义**（如「瓶颈 CT 10 分钟 → 产能 6 批/小时」）。不跳步。
4. **结论**：用一句话结论 + 关键数字支撑。每个结论都能追溯到某一步计算。
5. **管理建议**：分短期（不动产能/不动结构）与长期（投资、流程重构），每条建议标注它作用在流程的哪个环节（哪道工序、哪个参数）。
6. **可迁移要点**：提炼本案例的「套路」——下次遇到同类问题，分析路径是什么。这是把作业变成学习资产的关键一步。

## 参考文档

- `references/formula-handbook.md` — 全部公式的速查手册（含适用条件与易错点），计算时对照使用
- `references/worked-example.md` — 完整案例示范（烘焙坊产能分析，覆盖流程/瓶颈/利特尔法则/投资决策），格式照此

## 约定

- 计算过程完整展示，不跳步——学习辅助不是代写黑箱。
- 中间量必须标注含义；最终答案标注单位。
- 敏感性检查：关键结论至少做一个「参数变化会怎样」的小检验（如需求 +20% 结论是否反转），体现分析稳健性。
- 期末作业/考试场景：提供框架、推导与校验，提示用户自行完成核心论述。
- 用课程术语表述（瓶颈、节拍、在制品、订单赢家），便于直接用于作业。
