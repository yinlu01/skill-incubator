# 运营管理公式速查手册

计算时对照本手册：先核对**适用条件**，再套公式。每条含易错点。

## 1. 流程分析

### 周期时间（Cycle Time, CT）
- 定义：流程每产出**一个单位**所需时间
- 单工序：`CT = 任务时间`
- 串行流程（无并行）：`流程CT = 各工序CT之和`（若工序间无需等待）
- 含并行工序：取各路径时间的**最大值**

### 流程产能（Capacity）
- 单工序：`产能 = 1 / CT`（单位/时间）
- 含并行资源：`产能 = 资源数 / CT`
- **流程产能 = min(各工序产能)** ← 瓶颈决定

### 瓶颈（Bottleneck）
- 判定：产能最小的工序；多资源时比较「每资源产能」
- **易错点**：批量生产时要把批量换算成单位时间（例：烤箱一次烤 1 批 12 个用 30 分钟 → 产能 24 个/小时，不是 2 个/小时）

### 在制品 / 产出关系
- `吞吐率 TH = WIP / CT`（利特尔法则变形式）

## 2. 利特尔法则（Little's Law）

`L = λ × W`

| 符号 | 含义 |
|---|---|
| L | 系统中的平均数量（队长/在制品） |
| λ | 到达率/吞吐率（单位/时间） |
| W | 平均逗留时间（等待+服务） |

- **适用条件**：稳态系统（长期平均）、流守恒（不溢出、不丢弃）
- **易错点**：三个量单位必须一致（都用小时或都用分钟）；λ 用**实际吞吐率**而非理论产能（需求不足时吞吐率=需求率）
- 常用变体：
  - `W = L / λ`（已知队长和到达率，算等待时间）
  - 库存周转：`平均库存 = 吞吐率 × 平均停留时间`

## 3. 排队论

### M/M/1（单服务台，泊松到达，指数服务）
- 利用率：`ρ = λ / μ`（λ 到达率，μ 服务率；ρ ≥ 1 系统不稳定）
- 队长：`Lq = ρ² / (1-ρ)`；系统人数：`L = ρ / (1-ρ)`
- 等待时间：`Wq = ρ / (μ - λ)`；逗留时间：`W = 1 / (μ - λ)`
- **核心洞察**：ρ→1 时等待时间非线性爆炸（利用率 80% vs 90%，等待差好几倍）——这是「产能缓冲」的理论依据

### M/M/s（多服务台）
- 先算 `ρ = λ / (s·μ)`，查 Erlang C 表得等待概率 P_wait，再算 `Wq = P_wait / (s·μ - λ)`
- **易错点**：s 个服务台的产能是 s·μ，但排队恶化不是线性的——判断「加一个服务台值不值」要算 ΔW 与成本

## 4. 库存模型

### EOQ（经济订货批量）
`Q* = √(2·D·S / H)`

| 符号 | 含义 |
|---|---|
| D | 年需求量 |
| S | 每次订货固定成本 |
| H | 单位年持有成本 |

- 总成本：`TC = (D/Q)·S + (Q/2)·H + 采购成本`
- **易错点**：EOQ 处 S 与 H 成本**恰好相等**（可用于校验）；EOQ 曲线底部平缓——批量偏离 20% 成本只增约 2%，别过度精确

### 再订货点（ROP）
`ROP = 提前期内期望需求 + 安全库存 = d̄·LT + z·σ_d·√LT`

- z 值：服务水平 90% → 1.28；95% → 1.65；99% → 2.33
- **易错点**：σ 是**单位时间需求**的标准差，√LT 只开一次根（不是 LT²）

### 报童模型（单周期）
- 临界比例：`CR = Cu / (Cu + Co)`
  - Cu（缺货成本）= 售价 − 成本；Co（过量成本）= 成本 − 残值
- 最优订货量 = 需求分布的 CR 分位数（正态：`Q* = μ + z·σ`，z 查 CR 对应分位数）
- **核心洞察**：CR > 50% 说明缺货比压货贵，倾向多订

## 5. 产能与利用率

- `利用率 = 实际产出 / 有效产能`
- `有效产能 = 理论产能 × 可用率（扣除换型、休息、故障）`
- OEE（设备综合效率）= `时间开动率 × 性能开动率 × 良品率`
- **易错点**：比较扩产方案时，产能要折算到**同一时间口径**（如都用「每小时产出」）

## 6. 质量与变异

- 变异两类：common cause（系统固有，管理层责任）vs assignable cause（异常，现场可消除）
- 田口损失函数思想：偏离目标值即产生损失（二次型），不是「在规格内就零损失」
- **易错点**：把 common cause 当异常处理（过度调整，反而放大波动）

## 7. 供应链

- **牛鞭效应**成因：需求信号逐级放大——批量订货、价格波动、短缺博弈、需求预测各自修正
- 缓解：信息共享（POS 数据直达）、VMI、缩小批量、稳定价格（EDLP）
- **推拉边界**：推（预测驱动）到哪一层，拉（订单驱动）从哪一层开始——边界应放在「需求不确定性汇聚点」

## 8. 竞争策略（定性框架）

- 四维竞争：成本 / 质量 / 交付 / 柔性——**战略即取舍**，全都要 = 都不精
- 订单资格要素（Qualifier）vs 订单赢家（Order Winner）：
  - 资格要素：没有就出局，有了不多赚钱（如航空安全）
  - 赢家要素：客户为此选你（如顺丰的速度）
- 分析套路：先识别行业的资格线 → 再找本案例公司的赢家维度 → 看运营系统是否支撑该维度
